# Tanmayee Tivarekar — Beyond My Degrees

Complete HTML, CSS and JavaScript source for the portfolio, including the reversible scroll animations.

## Open the website

Extract this ZIP and open `index.html` in your browser. Keep all files and the `assets` folder together.

For a local development server, open a terminal in this folder and run:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

## Edit the portfolio

| File | What to edit |
| --- | --- |
| `index.html` | Page text, sections, navigation, photos and links |
| `styles.css` | Colours, fonts, spacing, responsive layouts and animation styling |
| `app.js` | Scroll motion, skill filters, experience tabs and research details |
| `assets/` | Photos, local fonts, font licences, CV and portfolio PDFs |

The source uses vanilla JavaScript with no package installation or build step. Motion respects the visitor's reduced-motion setting. You can upload this folder's contents to a static website host.
